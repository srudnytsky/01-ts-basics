# 01-ts-basics

 TypeScript homework #1.

## Requirements

- Node.js 20.19+ або 22.12+
- npm

## Run

```bash
npm install
npm run typecheck
npm run dev
```

For production-build check:

```bash
npm run build
```

## Structure

- `src/task-1.ts` — Simple types
- `src/task-2.ts` — Interfaces
- `src/task-3.ts` — Array typization
- `src/task-4.ts` — Function typization
- `src/task-5.ts` — Union Type
- `src/task-6.ts` — Generics
- `src/task-7.ts` — Promise
- `src/task-8.ts` — Axios and HTTP-requests
